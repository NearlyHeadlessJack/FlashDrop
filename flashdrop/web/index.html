      QUICK GUIDE

      两步，把文件送过去

      01

      发送端

      1. 选择文件或文件夹，检查清单。
      2. 点击「开启传输」，程序开始监听。
      3. 把界面上的本机 IP 和控制端口告诉对方。
      4. 对方确认保存位置后，传输自动开始。
      02

      接收端

      1. 选择「我要接收」，填写发送方地址与端口。
      2. 连接后查看文件数量与大小。
      3. 在系统窗口选择保存文件夹。
      4. 点击「开始接收」，等待校验完成。
      断点续传

      重新接收时选择同一个保存文件夹，程序会读取 .flashdrop 中的分片状态并自动继续。传输成功后会清理这些内部文件。

      连接不上？

      确认两台电脑在同一 IPv4 局域网。Windows 防火墙允许 Python 访问专用网络；macOS 允许 Python 接受传入连接，并检查「隐私与安全 → 本地网络」。必要时可先临时关闭防火墙测试。

      Mac ↔ Windows

      Windows 接收端会自动适配 macOS 的非法文件名、保留名和过长名称，并显示实际保存名。符号链接、扩展属性、可执行权限和 .app 包建议先打 zip 再传。

      使用边界

      本版本不加密、不认证，只适合可信局域网。浏览器关闭后后端仍会继续运行；关闭启动程序的终端窗口才会中止服务。

      文件只在本机与对方之间传输，不经过任何第三方服务器。
